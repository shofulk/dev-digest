# `@devdigest/api` — Fastify + Drizzle/Postgres, `:3001`

## Read when

- Request/DI flow, route map, diagrams → `./README.md`
- Implementing a feature → `./.spec/<feature>.spec.md` (write the spec first if missing)
- Starting any work here → `./INSIGHTS.md` first; at the end of the task run
  `engineering-insights` to append what is worth keeping (append-only)
- Adding or moving a file under `src/` (new module, new adapter, container/service/
  repository/route changes) → the `onion-architecture` skill first; it says which ring the
  file belongs to and what it may import. Check with `pnpm arch`.
- "Why is it built this way" → `./.doc/<topic>.md`
- Touching tests or CI → `../TESTING.md`

## Commands

`pnpm dev` (tsx watch, `:3001`) · `pnpm test` · `pnpm typecheck` · `pnpm lint` ·
`pnpm db:generate` · `pnpm db:migrate` · `pnpm db:seed`

Unit only: `pnpm exec vitest run --exclude '**/*.it.test.ts'`.
Integration only: `pnpm exec vitest run .it.test` (needs Docker).

## Conventions

- One Zod contract from `src/vendor/shared` drives **both** request validation and
  response serialization via `fastify-type-provider-zod`. Never hand-write a
  second shape for the response.
- A feature is `src/modules/<name>/` — `routes.ts` + service, registered in
  `modules/index.ts`. Cross-module helpers go in `modules/_shared/`, not in
  `platform/`.
- Services take their dependencies from the DI container
  (`src/platform/container.ts`) and talk to the world only through `src/adapters/*`.
  Tests swap in `src/adapters/mocks.ts`.
- Plugins (`helmet`, `cors`, `rate-limit`, SSE) register **before** modules.
- Errors go through `src/platform/errors.ts`; long work through `jobs.ts`,
  streaming through `sse.ts`.
- `*.it.test.ts` = DB-backed (testcontainers Postgres). Any other test must run
  without Docker and without network.

## Do not touch

- `src/vendor/**` — mirror of `@devdigest/shared`; edit the source there and the
  mirror follows.
- `src/db/migrations/**` — generated by `drizzle-kit`. Edit `src/db/schema.ts`,
  then `pnpm db:generate`.

## Gotchas

- The server never migrates on boot.
- Secrets are read only through `LocalSecretsProvider` (`src/adapters/secrets/local.ts`),
  backed by `~/.devdigest/secrets.json` with `process.env` as fallback.
- Every table already exists in the schema, including ones no starter code uses.
